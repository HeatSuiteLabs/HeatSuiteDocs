## About

**HeatSuite Cloud** is an optional, but highly useful backend solution with a responsive dashboard for remotely monitoring all devices within your HeatSuite deployment. This full web stack simplifies collecting, storing, processing, and visualizing HeatSuite device telemetry and manages file uploads. 

The **HeatSuite Cloud** software communicates bidirectionally with all connected devices over MQTT, stores all timeseries data in an InfluxDB database, including handling data from wearables. The dashboard provides device-level views, exports, upload/download workflows, and operational status tools. 

Lastly, all data is *fully data governed* and is not shared to any third parties, unless you chose to share that raw data. All data is encrypted, and no personally identifiable data is stored on the server. 

## Installation requirements

Below is the minimum server requirements to install the **HeatSuite Cloud** software package:

- Linux Ubuntu 24.10 or better
- 2 vCPU
- 2GB of RAM
- minimum 20 GB of storage, although this is highly dependent on how many devices are deployed.
